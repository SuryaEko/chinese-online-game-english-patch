# Chinese-Style Online Game (中国式网游 / MMOSimulator) – English Patch

An unofficial English translation for the Steam game **Chinese-Style Online Game** (MMOSimulator, build **V1.43**, by 648GameStudio).

* **5,084 in-game texts** translated ahead of time (menus, dialogue, quests, items, error codes, announcements). No online translator is used, so nothing shows up "pending" or flickers back to Chinese.
* **UI text is shrunk to 60%** so English fits the Chinese-sized buttons.
* **61 images with Chinese text** replaced: title logo, shop signs, red-packet envelopes, app icons, one-character badges, "N倍" multipliers and more.

Screens verified in-game: title menu, announcement, leaderboard. The rest was checked in previews only – bug reports welcome.

## Install

Requirements: Windows, the Steam version of the game (V1.43), and for the image patch **Python 3 + Pillow** (`pip install pillow`).

```powershell
git clone https://github.com/SuryaEko/chinese-online-game-english-patch
cd chinese-online-game-english-patch
powershell -ExecutionPolicy Bypass -File install.ps1 -GamePath "D:\SteamLibrary\steamapps\common\MMOSimulator\MMOSimulator"
```

The script downloads [BepInEx 6.0.0-pre.2 (IL2CPP)](https://github.com/BepInEx/BepInEx/releases/tag/v6.0.0-pre.2) and [XUnity.AutoTranslator 5.6.3.1](https://github.com/bbepis/XUnity.AutoTranslator/releases/tag/v5.6.3.1) from their official releases, copies the translation files, and patches the textures. Add `-SkipTextures` to install only the text translation (no Python needed). The first launch takes about a minute while BepInEx builds its files.

## Uninstall

1. Close the game and run `python _texture_backup\restore_textures.py` in the game folder (puts the original images back).
2. Delete `BepInEx`, `dotnet`, `winhttp.dll`, `doorstop_config.ini`, `changelog.txt`, `_texture_backup` from the game folder.

Steam → Properties → Installed Files → *Verify integrity* also restores the original images.

## Known limits

* **Video subtitles are not translated.** Cutscene videos 0–49 have Chinese subtitles burned into the picture; replacing them needs re-encoding and is not done.
* About 130 more textures with Chinese text are stored inside `resources.assets` itself and are not patched. Scratch-card posters with painted titles, photos and screenshots with small text are also left alone.
* Some signs were skipped because the automatic edit looked bad (building exit sign, park gate).
* A Steam update may overwrite the data files and bring back the Chinese images. Run `install.ps1` again; the text translation itself is not affected.
* The texture patch is tied to build V1.43 and refuses to run if the file sizes differ.
* Some strings are quick or literal translations of memes and slang; fixes via pull request are welcome.

## Files

| Path | What it is |
|---|---|
| `translation/_AutoGeneratedTranslations.txt` | `中文=English` pairs read by XUnity.AutoTranslator |
| `translation/_AutoGeneratedresizer.txt` | font-size rules per UI root |
| `translation/AutoTranslatorConfig.ini` | plugin config (no online translator) |
| `textures/` | edited PNGs named by Unity path ID, `manifest.json`, patch and restore scripts |
| `tools/` | scripts used to make the images; development only, paths are hard-coded to the author's machine |
