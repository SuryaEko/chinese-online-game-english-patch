# Docs

| File | Read it when |
|---|---|

| [TOOLS-AND-COMMANDS.md](TOOLS-AND-COMMANDS.md) | You need the exact commands: install BepInEx/XUnity, export assets with AssetStudio, patch textures. |
| [PITFALLS.md](PITFALLS.md) | Something does not work. Every dead end hit in this project and its fix. |
| [TRANSLATION-FORMAT.md](TRANSLATION-FORMAT.md) | You edit `translation/*.txt`: escaping rules, regex rules, resizer rules, glossary. |
| [TEXTURES.md](TEXTURES.md) | You add or change an edited image. |
| [STATUS.md](STATUS.md) | You want to know what is done and what is left. |
