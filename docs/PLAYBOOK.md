# Playbook: translating a Unity game (worked example: MMOSimulator)

Target game: Steam "Chinese-Style Online Game" (MMOSimulator, 648GameStudio), Unity 2020.3.1f1, **IL2CPP**, 64-bit,
build V1.43. Goal: English, everything pre-translated (no online translator, nothing "pending").

## 0. Ground rules that paid off
* Ask the user before: downloading tools (state name, source, size), modifying game data files, publishing a repo.
  Say what is reversible. Keep a byte-exact backup of anything overwritten.
* Work in the session scratchpad, not in the game folder, except for the final installed files.
* Verify by looking at the running game (screenshot), not by assuming. Close the game before touching data files.
* The user reports leftovers as screenshots. Treat each screenshot as a list of failing strings/images.

## 1. Identify the game
1. `ls` the game folder. `GameAssembly.dll` + `*_Data/il2cpp_data` = IL2CPP; `Managed/Assembly-CSharp.dll` = Mono.
2. Unity version: first bytes of `globalgamemanagers` (regex `20\d\d\.\d+\.\d+\w*`).
3. `global-metadata.dat` header: magic `0xfab11baf`, version at offset 4 (27 here).
4. Find the source language and text locations: scan `resources.assets` and `global-metadata.dat` for CJK runs.
   * Strings in code live in the metadata string-literal table (see `tools/extract.py`).
   * Data tables live in **TextAssets (XML)** inside `resources.assets`.
   * Images live in Texture2D; videos in VideoClip (`.webm`).

## 2. Install the runtime translator (text)
BepInEx 6.0.0-pre.2 `Unity.IL2CPP-win-x64` + XUnity.AutoTranslator `BepInEx-IL2CPP` 5.6.3.1.
Unzip both into the game folder (they only add files). First launch builds interop files (~1 min).
Config: `Endpoint=` (empty), `FromLanguage=zh`, `Language=en`. Empty endpoint = only the cache file is used.
Details: [TOOLS-AND-COMMANDS.md](TOOLS-AND-COMMANDS.md).

## 3. Extract EVERY string (this is where the first pass failed)
1. Metadata string literals -> `tools/extract.py`.
2. **Export all TextAssets with AssetStudio** and parse the XML with a real XML parser (`tools/missing2.py`).
   * Use `ElementTree`, not regex: values with colour tags are wrapped in `CDATA`
     (`<![CDATA[<color=#00FFAC>]]>text<![CDATA[</color>]]>`), and the game shows the *whole* string with tags.
   * Take element text, tails and attribute values; split on newlines; strip.
   * The first pass used a length-prefix scan limited to 4 KB per string and silently missed big tables
     (item names/descriptions, NPC chat). ~2,400 strings were missing. Do not use that scan alone.
3. Skip: font character lists (`Chinese`, `LineBreaking*`), `SensitiveWords*`, comma-separated pools of player
   nicknames (they are split at runtime), garbage hits from binary data (random symbols).
4. Diff against what is already translated: `missing2.py` prints only the new ones.

## 4. Translate
* Translate in batches of ~400-500 strings, files `tr2/mNN.txt` as `index|English` (or `phrase => English`).
* Keep format tokens, `<color=..>` tags, `{0}`, `\n` exactly. `build2.py` checks tag parity and leftover CJK.
* Pattern families (season medals S1..S19, "Day N") are done by rules, not by hand (`RULES` in `build2.py`,
  regex lines in `tools/regex.txt`).
* Glossary decisions are in [TRANSLATION-FORMAT.md](TRANSLATION-FORMAT.md). Stay consistent.
* Write files with the **Write tool**, not shell heredocs (see PITFALLS: heredoc/backslash problems).

## 5. Build and install the cache
`build3.py` merges everything into `final.json`, escapes it, appends regex lines, writes
`_AutoGeneratedTranslations.new.txt`. Copy it to `BepInEx/Translation/en/Text/_AutoGeneratedTranslations.txt`.
Launch, screenshot, look for Chinese. Repeat steps 3-5 for what the user reports.

## 6. Fit the text
English is longer, so buttons clip. XUnity resizer: `BepInEx/Translation/en/Text/*resizer.txt`,
`/UI_Root=ChangeFontSizeByPercentage(0.6)` per UI root (prefix match on the object path, NOT "contains").
Find roots with `EnableTextPathLogging=True` and read `Path :` lines in `LogOutput.log`, or scan
`resources.assets` for `UI_*` names. 0.6 fits; 0.75 still clips.

## 7. Images
XUnity texture replacement does **not** work on this IL2CPP game. Patch pixels in the `.resS` files instead.
Full procedure: [TEXTURES.md](TEXTURES.md).

## 8. Videos
Cutscenes 0-49 have hard-burned Chinese subtitles. Needs ffmpeg (not installed) and a list of cues per video.
Not done. Options and notes in [STATUS.md](STATUS.md).

## 9. Ship
* Repo layout is in the root README. `install.ps1` downloads the runtime from official releases.
* Before pushing: `git ls-files` must not contain BepInEx binaries, `.resS`, `.assets`, `_texture_backup/*.orig`.
* After a texture change run the round trip: restore -> patch -> compare SHA1 of every patched range.
* Commit messages end with the Co-Authored-By line given by the session.
